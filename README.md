# MBTI 快速自測（40 題）

中興大學 生管所 1151 學期「人力資源管理」課堂用：讓沒做過 MBTI 的同學 5 分鐘內抓到自己可能偏向哪一型，上課對照用。

線上網址：https://halcyone1234-ux.github.io/mbti-quick/

- 40 題、四個向度（E/I、S/N、T/F、J/P）各 10 題，五點量表，穿插反向題。
- 點選項自動跳下一題；答案存在本機 localStorage，可中斷後繼續。
- 結果頁顯示四個向度的連續位置（百分比），靠近中間的向度標「門檻附近」，呼應課堂「連續變數砍二分」的提醒；另附 16 型一句話說明、關鍵字與參考方向。
- 純靜態單一 `index.html`，無後端、不蒐集資料。簡化版自我評估，非正式 MBTI® 測驗。
